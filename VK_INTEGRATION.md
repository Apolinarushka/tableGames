# Интеграция «Твой ход» с VK Mini Apps

Игра продолжает работать как обычный сайт. Режим VK включается только при наличии
подписанных параметров запуска `vk_app_id`, `vk_user_id` и `sign`.

## Какие значения нужны

1. `VK_APP_ID` — числовой ID приложения.
2. `VK_APP_SECRET` — защищённый ключ приложения.

Создайте мини-приложение на [портале VK для разработчиков](https://dev.vk.com/ru), затем откройте
[настройки мини-приложения](https://dev.vk.com/ru/mini-apps/management/settings):

- ID приложения скопируйте в `VK_APP_ID`;
- защищённый ключ (API secret) скопируйте в `VK_APP_SECRET`;
- в режиме разработки и в настройках размещения укажите URL `https://chess.callsec.ru/`.

Сервисный ключ и токен пользователя для текущей интеграции не нужны. Они понадобятся только при
подключении дополнительных методов VK API или размещении статики на хостинге VK.

Защищённый ключ используется только сервером для HMAC-проверки параметров запуска.
Его нельзя помещать в HTML, клиентский JavaScript или отправлять в Git.

Локально скопируйте `.env.vk.example` в `.env` и заполните значения. Docker Compose
передаст их контейнеру игры.

## URL приложения

Для разработки и публикации укажите HTTPS-адрес игры:

`https://chess.callsec.ru/`

Реальный запуск проверяется внутри VK. Для проверки адаптивной вёрстки без ключей
можно открыть:

`http://localhost:4173/?vk_test=1`

Тестовый режим только подставляет демонстрационный профиль в интерфейсе и не создаёт
подтверждённую VK-сессию.

## Что уже подключено

- официальный VK Bridge;
- `VKWebAppInit`;
- получение профиля через `VKWebAppGetUserInfo`;
- обработка viewport и safe-area мобильного клиента VK;
- серверная проверка подписи launch parameters;
- стабильная серверная сессия для одного VK ID;
- методы приглашения друзей и добавления приложения в избранное в платформенном адаптере.
