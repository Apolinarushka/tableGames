# Тихий ход

Локальный браузерный клуб настольных игр: шашки, поддавки, уголки, шахматы,
домино «Козёл» и домино «Пятёрочки».

## Запуск

Репозиторий запускается непосредственно из `E:\tableGames`.

Дважды щёлкните `start.bat` или выполните в этой папке:

```powershell
npm start
```

Затем откройте `http://localhost:4173`.

Чтобы зайти с телефона или другого компьютера в той же сети, используйте адрес
`В локальной сети`, который появится в окне запуска. При первом запуске Windows
может попросить разрешить Node.js доступ к частной сети.

## Запуск в Docker

Из папки `E:\tableGames` выполните:

```powershell
docker compose up -d --build
```

Игра откроется по адресу `http://localhost:4173`. Посмотреть состояние:

```powershell
docker compose ps
```

Остановить контейнер:

```powershell
docker compose down
```

## Управление

- клик по полу или предмету — подойти к указанному месту;
- клик по столу — подойти, сесть и открыть выбор игры;
- клик по человеку — открыть его анкету;
- стол 05 — партия против бота.

В клубе работают игровые правила, уровни сложности ботов, таймер, звук,
кастомизация, локальная история и рейтинг, общий чат и чат за столом.
